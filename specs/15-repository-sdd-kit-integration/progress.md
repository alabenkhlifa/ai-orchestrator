Ingestion is split into a pure `RepositoryKits.publish_package/2` (no disk/network I/O, package content is only measured/hashed/base64-encoded, never executed) plus a thin `mix repository_kits.publish` CLI wrapper that walks a directory and refuses (never dereferences) a symlink. Inspection UI is a new global `/repository-kits` LiveView under the existing `:authenticated` live_session (same boundary as `/ai-connections`), read-only by construction — no form, edit, or delete control anywhere.
