### 2026-08-09 - Task 1 implemented and verified: immutable kit package catalog

- Completed: AC-02, AC-03. Adopted the Task Proof Gate for this spec (`## Proof Scope Gate` — `Applies to: Task 1.`, `Proof scope: Focused` on Task 1) since Task 1 was the next unfinished task being refined and the proof runner is available; `## Status` set to `In Progress`. Started the shared `sdd_orchestrator_postgres` container (it was stopped) so the worktree's proof commands could run.
- Implementation design decided for Task 1 (engineering mechanism, not a business-rule change, so not written to design.md): `repository_kit_packages` is a global, non-project-scoped table (no `project_id`) with a Postgres reject-update trigger for true immutability, mirroring `repository_execution_profiles`'s pattern. The digest is a server-computed sha256 over the sorted per-file `{path, sha256, size, executable}` manifest — never accepted as caller input, so tamper is always detectable by recomputation. Provenance requires `ref_type: "commit"` and a 40/64-hex `ref`; a branch- or tag-shaped ref (`"main"`, `"latest"`, `"HEAD"`) is rejected as a mutable reference (AC-03). `supported_adapters` validates against the known `~w(claude_code codex)` set. Supersession is derived at read time via `Version.compare/2` over `{source, publisher}` families, never stored, so no immutable row is ever mutated to record it. Ingestion is split into a pure `RepositoryKits.publish_package/2` (no disk/network I/O, package content is only measured/hashed/base64-encoded, never executed) plus a thin `mix repository_kits.publish` CLI wrapper that walks a directory and refuses (never dereferences) a symlink. Inspection UI is a new global `/repository-kits` LiveView under the existing `:authenticated` live_session (same boundary as `/ai-connections`), read-only by construction — no form, edit, or delete control anywhere.
